# Colour system is law

Before touching any colour, class with `accent`/`brand`, shadow, or transition,
read [DESIGN.md](DESIGN.md). Short version: neutral chrome, ink text, cobalt for
actions only, coral for brand marks only, category colours for variety, content
text never theme-coloured, and never `transition-all`.
